# HTML5 Tech Blue · 1SMX

Material docent per a RA1 (HTML i CSS) i RA2 (introducció a la programació amb JavaScript).

## Contingut del RA2

La teoria inclou els apartats 2.1–2.12: conceptes i eines de programació, estructura d'un programa, variables i constants, operadors, entrada i sortida, programació estructurada, proves, estructures de selecció (`if`, `else if` i `else`), cadenes de caràcters (strings), llistats (arrays), estructures iteratives (`while` i `for`) i documentació de programes.

Els exemples de JavaScript utilitzen `prompt()`, `alert()` i `console.log()`. No s'hi treballa encara la manipulació del DOM. Els fitxers JavaScript externs s'enllacen des de l'HTML amb l'etiqueta `<script>`; CSS no carrega fitxers JavaScript.

## Ús

Obre `index.html` en un navegador. La web és estàtica i està preparada per publicar-se a GitHub Pages. Mantén l'estructura de carpetes perquè els estils, scripts i imatges es carreguin correctament.
