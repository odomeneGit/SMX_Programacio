Aprèn a construir una pàgina web des de l'estructura HTML fins a la presentació amb CSS. Cada concepte combina codi, resultat al navegador i exemples per practicar.

Objectiu del RA1 · Crear prototips visuals de programes i aplicacions web amb HTML i CSS.
1.1

Origen i evolució d'HTML i CSS

HTML i CSS són llenguatges amb funcions diferents però complementàries: HTML estructura el contingut i CSS en defineix la presentació. En aquest RA treballarem amb HTML5 i CSS per crear prototips visuals.

HTMLHyperText Markup LanguageMarcatge del contingut i estructura del document.
CSSCascading Style SheetsFulls d'estil per controlar la presentació.
EstàndardsWeb estàndardRegles i especificacions que afavoreixen una web interoperable.

1.3

Estructura dels documents HTML

Una pàgina HTML5 parteix d'una estructura bàsica formada pel tipus de document, l'arrel, la capçalera i el cos.

HTML 
<!DOCTYPE html>
<html lang="ca">
<head>
  <meta charset="UTF-8">
  <title>La meva pàgina</title>
</head>
<body>
  <h1>Hola, 1SMX!</h1>
</body>
</html>
Resultat al navegador

Hola, 1SMX!

El body conté el contingut visible.

El <head>

Informació que el navegador necessita però que normalment no apareix com a contingut de la pàgina.

<meta charset="UTF-8">Defineix la codificació dels caràcters.
<meta name="viewport">Ajuda a adaptar la visualització a diferents dispositius.
<title>Text que apareix a la pestanya del navegador.
<link>Relaciona el document amb recursos com CSS o favicon.
<script>Permet vincular o incorporar JavaScript al document.
Exemple complet del <head> 
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>La meva pàgina</title>
  <link rel="stylesheet" href="css/styles.css">
  <script src="js/app.js" defer></script>
</head>
Resultat al navegador

La meva pàgina

charset → UTF-8

viewport → adaptació a dispositius

link → CSS vinculat

script → JavaScript vinculat

Etiquetes semàntiques + id i class

Les etiquetes semàntiques donen significat a l'estructura: header, footer, main, nav, article, section i aside. Per si soles no modifiquen l'aspecte: el CSS és qui el presenta.

<header>Capçalera
<nav>Menú
<main>Contingut principal
<article>Article
<section>Secció
<aside>Contingut complementari
<footer>Peu de pàgina
id i class 
<section id="contingut"
         class="bloc important">
  Contingut de la secció
</section>
Navegador
#contingut.blocid identifica de manera única; class agrupa elements.
1.6

Estructura dels documents CSS

CSS es vincula al document HTML habitualment amb link. Un full d'estils conté selectors i declaracions de propietats. La precedència depèn, entre altres factors, de l'especificitat dels selectors.

HTML + CSS 
<link rel="stylesheet"
      href="css/estils.css">

/* estils.css */
p { color: #2563EB; }
.important { font-weight: bold; }
#principal { color: #155E75; }
Resultat al navegador

Un paràgraf afectat per CSS.

Una classe pot canviar el pes del text.

Un id és més específic que un selector d'element.
