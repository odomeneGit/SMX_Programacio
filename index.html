Pas 1. Què és CSS i per a què serveix?

CSS significa Cascading Style Sheets, és a dir, fulls d'estil en cascada. HTML defineix el contingut i l'estructura; CSS defineix com es presenta: colors, tipus de lletra, mides, espais, vores i distribució.

HTML · contingut 
<h1>Benvinguts a la meva web</h1>
<p>Aquesta és una pàgina d'exemple.</p>
Sense estils personalitzats

Benvinguts a la meva web

Pas 2. Connectar el CSS extern amb HTML

És recomanable guardar els estils en un fitxer separat, per exemple css/estils.css. D'aquesta manera podem canviar el disseny sense reescriure el contingut HTML.

  1. Crea una carpeta anomenada css.
  2. Dins, crea el fitxer estils.css.
  3. Afegeix l'etiqueta link dins de head del document HTML.
  4. Escriu les regles CSS al fitxer estils.css.
index.html 
<head>
  <meta charset="UTF-8">
  <title>La meva web</title>
  <link rel="stylesheet" href="css/estils.css">
</head>
css/estils.css 
body {
  font-family: Arial, sans-serif;
  color: #17212B;
}

h1 {
  color: #2563EB;
}
Comprova la ruta: si el fitxer CSS és dins la carpeta css, escriu href="css/estils.css". El nom i les majúscules han de coincidir amb el fitxer real.

Pas 3. Entendre una regla CSS

Una regla CSS té tres parts principals: selector (què volem modificar), propietat (què volem canviar) i valor (com volem que quedi).

HTML · index.html 
<p>Aquest paràgraf és blau i fa 18 píxels.</p>
CSS · estils.css 
p {
  color: blue;
  font-size: 18px;
}
Resultat al navegador

Aquest paràgraf és blau i fa 18 píxels.

  • p és el selector: s'aplica als paràgrafs.
  • color i font-size són propietats.
  • blue i 18px són valors.
  • Les claus { } agrupen les declaracions i el punt i coma ; tanca cada declaració.

Pas 6. Quina regla té prioritat? Precedència i especificitat

De vegades dues regles intenten canviar la mateixa propietat del mateix element. El navegador ha de decidir quin valor utilitza. Aquesta decisió forma part de la cascada.

Per començar, recorda aquesta idea pràctica: un selector que identifica un element de manera més concreta acostuma a tenir més pes que un selector general.

Tres regles per al mateix paràgraf 
p { color: blue; }
.avís { color: green; }
#missatge { color: red; }
HTML del resultat

Aquest paràgraf és vermell perquè té id="missatge".

El selector d'id és més específic que el de classe i el d'etiqueta.

  1. El selector p és general: afecta tots els paràgrafs.
  2. El selector .avís afecta els elements amb aquesta classe.
  3. El selector #missatge identifica un element concret i, en aquest exemple, guanya.
  4. Si dues regles tenen el mateix pes, normalment preval la que apareix més avall al full d'estils.
Consell: evita posar estils diferents i contradictoris a la mateixa propietat sense necessitat. Escriu regles clares i comprova el resultat al navegador.

Ampliació: propietats d’ajust — flex-wrap, flex-flow i align-content

flex-wrap indica si els elements poden passar a una altra línia quan no caben:

  • nowrap: tots intenten mantenir-se en una sola línia (valor per defecte).
  • wrap: els elements passen a línies noves quan cal.
  • wrap-reverse: permet diverses línies, però n’inverteix la disposició transversal.

flex-flow és una abreviació que combina flex-direction i flex-wrap. Per exemple: flex-flow: row wrap;.

align-content distribueix les línies entre si quan hi ha diverses línies (normalment amb flex-wrap: wrap) i espai transversal disponible. No substitueix align-items, que alinea els elements dins de cada línia.

  display: flex;
  flex-flow: row wrap;
  align-content: space-between;
  min-height: 260px;
}
Amb wrap
123456
Regla pràctica: comença amb display: flex, decideix flex-direction, ajusta l’espai amb justify-content i l’alineació transversal amb align-items. Després afegeix gap per controlar la separació entre els elements.

2.9

Estructures de selecció

Les estructures de selecció permeten que el programa prengui decisions. Segons el resultat d'una condició (cert o fals), s'executa un bloc d'instruccions o un altre.

if

Executa un bloc només quan la condició és certa.

if 
let edat = 20;
if (edat >= 18) {
  console.log("Ets major d'edat");
}
Resultat

Ets major d'edat

if / else

Permet escollir entre dues alternatives: si la condició és certa s'executa if; si és falsa, s'executa else.

if / else 
let numero = 7;
if (numero % 2 === 0) {
  console.log("Nombre parell");
} else {
  console.log("Nombre senar");
}
Resultat

Nombre senar

if / else if / else

Quan hi ha més de dues possibilitats, podem encadenar condicions. Es comproven en ordre i s'executa el primer bloc que compleix la seva condició.

Classificar una nota 
let nota = 7;
if (nota < 0 || nota > 10) {
  console.log("Nota no vàlida");
} else if (nota >= 5) {
  console.log("Aprovat");
} else {
  console.log("Suspès");
}

Aprovat

Prova també 4, 5, 10 i 12.
Per a les pràctiques: abans d'escriure una condició, pensa quines situacions poden passar, quina comparació necessites i què ha de mostrar el programa en cada cas.

2.11

Estructures iteratives

Una estructura iterativa, també anomenada bucle, permet repetir un bloc d'instruccions diverses vegades. S'utilitza quan necessitem fer una mateixa tasca amb diferents dades o repetir-la mentre es compleixi una condició.

El bucle while

while repeteix les instruccions mentre la condició sigui certa. La condició es comprova abans d'executar el bloc; per això pot ser que no s'executi cap vegada.

Exemple 1 · Comptar amb while 
let comptador = 1;
while (comptador <= 5) {
  console.log(comptador);
  comptador++;
}

2.12

Documentació de programes

Documentar un programa consisteix a afegir informació que ajudi a entendre què fa, com està organitzat i com s'ha d'utilitzar. Un codi ben documentat és més fàcil de llegir, corregir i mantenir.

Comentaris d'una línia

Comencen amb //. El navegador no els executa: serveixen per explicar una instrucció o una part del programa.

Exemple 1 · Comentaris d'una línia 
// Calcular el preu amb IVA
let preu = 50;
const IVA = 0.21;
let preuFinal = preu * (1 + IVA);
console.log(preuFinal); // Mostra el resultat
Consola

60.5

Els comentaris no apareixen a la sortida.

Comentaris de diverses línies

Comencen amb /* i acaben amb */. Són útils per explicar el propòsit general d'un fragment de codi o deixar una nota més extensa.

Exemple 2 · Comentari de bloc 
/* Aquest programa calcula
   la suma de dos nombres. */
let a = 8;
let b = 5;
let suma = a + b;
console.log(suma);

Documentar les parts del programa

És recomanable separar el codi en blocs i indicar què fa cada part: dades inicials, entrada, càlculs i sortida. Els noms de variables també han de ser descriptius.

Exemple 3 · Programa documentat 
// 1. Entrada de dades
let base = 10;
let altura = 4;

// 2. Càlcul de l'àrea
let area = base * altura / 2;

// 3. Sortida del resultat
console.log("Àrea del triangle:", area);
Consola

Àrea del triangle: 20

Bones pràctiques

  • Utilitza noms de variables que expliquin què contenen: preuTotal és millor que x.
  • Comenta les parts que poden resultar difícils d'entendre; no cal comentar cada línia evident.
  • Organitza el codi amb salts de línia i indentació.
  • Elimina comentaris antics o que ja no siguin correctes.
  • Comprova que els comentaris expliquen el que realment fa el programa.
Recorda: els comentaris ajuden a entendre el codi, però no substitueixen un codi clar, ordenat i amb noms descriptius.
