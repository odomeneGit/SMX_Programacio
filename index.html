Estructura dels documents CSS

Pas 1. Què és CSS i per a què serveix?

CSS significa Cascading Style Sheets, és a dir, fulls d'estil en cascada. HTML defineix el contingut i l'estructura; CSS defineix com es presenta: colors, tipus de lletra, mides, espais, vores i distribució.

HTML · contingut 
<h1>Benvinguts a la meva web</h1>
<p>Aquesta és una pàgina d'exemple.</p>
Sense estils personalitzats

Benvinguts a la meva web

Aquesta és una pàgina d'exemple.

Pas 2. Connectar el CSS extern amb HTML

És recomanable guardar els estils en un fitxer separat, per exemple css/estils.css. D'aquesta manera podem canviar el disseny sense reescriure el contingut HTML.

  1. Crea una carpeta anomenada css.
  2. Dins, crea el fitxer estils.css.
  3. Afegeix l'etiqueta link dins de head del document HTML.
  4. Escriu les regles CSS al fitxer estils.css.
index.html 
<head>
  <meta charset="UTF-8">
  <title>La meva web</title>
  <link rel="stylesheet" href="css/estils.css">
</head>
css/estils.css 
body {
  font-family: Arial, sans-serif;
  color: #17212B;
}

h1 {
  color: #2563EB;
}
Comprova la ruta: si el fitxer CSS és dins la carpeta css, escriu href="css/estils.css". El nom i les majúscules han de coincidir amb el fitxer real.

Pas 3. Entendre una regla CSS

Una regla CSS té tres parts principals: selector (què volem modificar), propietat (què volem canviar) i valor (com volem que quedi).

HTML · index.html 
<p>Aquest paràgraf és blau i fa 18 píxels.</p>
CSS · estils.css 
p {
  color: blue;
  font-size: 18px;
}
Resultat al navegador

Aquest paràgraf és blau i fa 18 píxels.

  • p és el selector: s'aplica als paràgrafs.
  • color i font-size són propietats.
  • blue i 18px són valors.
  • Les claus { } agrupen les declaracions i el punt i coma ; tanca cada declaració.

Els comentaris serveixen per deixar notes al codi. El navegador no els mostra com a contingut de la pàgina.

Pas 6. Quina regla té prioritat? Precedència i especificitat

De vegades dues regles intenten canviar la mateixa propietat del mateix element. El navegador ha de decidir quin valor utilitza. Aquesta decisió forma part de la cascada.

Per començar, recorda aquesta idea pràctica: un selector que identifica un element de manera més concreta acostuma a tenir més pes que un selector general.

Tres regles per al mateix paràgraf 
p { color: blue; }
.avís { color: green; }
#missatge { color: red; }
HTML del resultat

Aquest paràgraf és vermell perquè té id="missatge".

El selector d'id és més específic que el de classe i el d'etiqueta.

  1. El selector p és general: afecta tots els paràgrafs.
  2. El selector .avís afecta els elements amb aquesta classe.
  3. El selector #missatge identifica un element concret i, en aquest exemple, guanya.
  4. Si dues regles tenen el mateix pes, normalment preval la que apareix més avall al full d'estils.
Consell: evita posar estils diferents i contradictoris a la mateixa propietat sense necessitat. Escriu regles clares i comprova el resultat al navegador.

2. Colors i fons

color canvia el color del text; background-color canvia el fons de l'element. Pots escriure colors amb noms (red), codis hexadecimals (#2563EB) o funcions de color com rgba().

CSS 
.avís {
  color: #FFFFFF;
  background-color: #155E75;
}
Resultat al navegador

Text blanc sobre fons blau verdós.

background-image permet utilitzar una imatge com a fons. La ruta dins de url() ha d'apuntar al fitxer correcte.

CSS 
.portada {
  background-image: url("../img/fons.jpg");
  background-position: center center;
  background-size: cover;
}
Què fa cada propietat?
  • background-image: tria la imatge.
  • background-position: situa la part visible de la imatge.
  • background-size: cover: amplia la imatge per cobrir l'espai; pot retallar una part.
Si la imatge no apareix, comprova el nom, l'extensió i la ruta relativa. Una ruta incorrecta és una de les causes més habituals.

4. Model de caixa: border, margin i padding

Per entendre l'espaiat, imagina que cada element HTML és una caixa. La caixa té contingut, espai intern, vora i espai extern.

CSS

  padding: 16px;
  margin: 20px;
}
Resultat al navegador
Contingut de la targeta

Padding: espai entre el text i la vora. Margin: espai exterior a la vora.

  • border: dibuixa una vora. Exemple: border: 1px solid #333;. També hi ha border-top, border-right, border-bottom i border-left.
  • margin: espai exterior a la caixa. Es pot indicar per a tots els costats o amb margin-top, margin-right, margin-bottom i margin-left.
  • padding: espai interior entre el contingut i la vora. També té les quatre variants per costat.
  • border-collapse: collapse;: en taules, fa que les vores de cel·les adjacents es mostrin juntes i no com a vores dobles.

6. Distribuir elements amb Flexbox

Flexbox és un sistema de maquetació per distribuir elements en una dimensió: en una fila o en una columna. S’activa al contenidor pare amb display: flex;; les propietats de distribució s’apliquen al pare i les de mida o ordre, als elements fills.

Pas 1. Identifica el contenidor i els fills

HTML

  <div class="element">Element 3</div>

Pas 2. Activa Flexbox i tria la direcció

Amb display: flex;, els fills passen a ser elements flexibles. Per defecte es col·loquen en fila. flex-direction permet canviar la direcció principal:

  • row: en fila, d’esquerra a dreta (valor per defecte).
  • row-reverse: en fila, en ordre visual invers.
  • column: en columna, de dalt a baix.
  • column-reverse: en columna, en ordre visual invers.
CSS 
.fila {
  display: flex;
  flex-direction: row;

Pas 4. Alinea els elements en l’eix transversal amb align-items

align-items controla l’alineació dels fills en l’eix transversal, és a dir, l’eix perpendicular al principal. Per veure bé la diferència, dona al contenidor una alçada (o amplada, si està en columna) suficient.

  • stretch: els elements s’estiren per ocupar l’espai transversal disponible si no tenen una mida fixada en aquest eix.
  • flex-start: s’alineen al principi de l’eix transversal.
  • center: queden centrats.
  • flex-end: s’alineen al final.

Ampliació: propietats d’ajust — flex-wrap, flex-flow i align-content

flex-wrap indica si els elements poden passar a una altra línia quan no caben:

  • nowrap: tots intenten mantenir-se en una sola línia (valor per defecte).
  • wrap: els elements passen a línies noves quan cal.
  • wrap-reverse: permet diverses línies, però n’inverteix la disposició transversal.

flex-flow és una abreviació que combina flex-direction i flex-wrap. Per exemple: flex-flow: row wrap;.

align-content distribueix les línies entre si quan hi ha diverses línies (normalment amb flex-wrap: wrap) i espai transversal disponible. No substitueix align-items, que alinea els elements dins de cada línia.

CSS d’exemple 
.fila {
  display: flex;
  flex-flow: row wrap;
  align-content: space-between;
  min-height: 260px;
}
